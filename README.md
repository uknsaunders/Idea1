# MoneyMath — free finance calculators

A zero-cost, zero-maintenance passive-income website: free finance calculators hosted on GitHub Pages, earning from tips, affiliate links and ads.

- **Live site:** https://uknsaunders.github.io/Idea1/ (after the one-click step in [SETUP.md](SETUP.md))
- **Turn on income:** edit [`site/assets/config.js`](site/assets/config.js), see [SETUP.md](SETUP.md)
- **Get traffic:** [PROMOTION.md](PROMOTION.md)

## Calculators
Compound interest · Mortgage/loan with overpayments · Savings goal · FIRE/retirement · Inflation · Percentage

## How it works
- `build.py` generates every page into `site/` (Python standard library only).
- `.github/workflows/deploy.yml` rebuilds and deploys to GitHub Pages on every push.
- No backend, no database, no running costs.
